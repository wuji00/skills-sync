# FAQ 与资源限制

## 资源限制

### API 调用限制

| API | 单次输入限制 | 单次输出限制 |
|-----|------------|------------|
| addMessage | 40,000 tokens | - |
| searchMemory | 40,000 tokens | 事实记忆 25 条、偏好 25 条、Tool 25 条、Skill 25 条 |
| Chat | 8,000 tokens | 事实记忆 25 条、偏好 25 条 |

### 速率限制

- 每分钟总 tokens：≤ 400,000
- 建议 QPS：≤ 50（非硬限制，高并发可能受平台容量影响）

### 文档上传限制

- 支持类型：PDF, DOCX, DOC, TXT, JSON, MD, XML
- 单文件：≤ 100 MB，≤ 500 页
- 单次上传：≤ 20 个文件
- Skill 单文件 (.md)：≤ 100KB
- Skill 包 (.zip)：≤ 20MB，解压后 ≤ 200 文件

### 配额说明

- 免费配额按**开发者账户**计算，同账户下所有项目共享
- 失败请求（鉴权失败、参数错误、超限等）不消耗配额
- 超过单次调用限制的请求返回对应错误码，不扣配额

## 常见问题

### MemOS 和标准 RAG 有什么区别？

| 维度 | RAG | MemOS |
|------|-----|-------|
| 结果形态 | 原始文本段落 | 精炼的记忆单元（更少 token） |
| 检索范围 | 全量语料扫描 | 分层调度，命中更快 |
| 个性化 | 无 | 自动提取用户偏好 |
| 进化能力 | 静态 | 通过反馈/对话动态更新 |

RAG 提供外部知识，MemOS 提供内部记忆。两者可以结合使用。

### MemOS Cloud 核心接口是什么？

- `addMessage`：写入原始信息，自动处理为记忆
- `searchMemory`：检索相关记忆

### 记忆会膨胀吗？

不会。MemOS 通过合并、压缩、归档机制管理记忆生命周期，低价值记忆降权，高价值记忆合并或固化。

### 会影响推理延迟吗？

不会。调度器异步运行，记忆检索通常 600ms 内返回。

### 支持私有化部署吗？

支持。MemOS 同时提供 **Cloud（云服务）** 和 **Open Source（开源自部署）** 两套方案。本 skill 只负责 Cloud API 集成；不要把 Cloud API 调用和开源/本地部署、MCP、Dashboard、CLI 安装的步骤混在一段里，除非用户明确要走那条路径。

### Cloud 和 Open Source 怎么选？

| 方案 | 适合 | 特点 |
|------|------|------|
| Cloud 云服务 | 想几分钟接入、免维护存储 | 调 `https://memos.memtensor.cn/api/openmem/v1`，用 API Key；本 skill 默认走这条 |
| Open Source 自部署 | 要自选 LLM/后端、深度二开 | 自建服务，base URL 指向自有部署 |

只有用户已确认走自部署，才使用其本地 base URL；否则一律用 Cloud 默认地址。

### 可以和已有 RAG/知识图谱结合吗？

可以。MemOS 记忆单元可以接入 RAG 的向量检索层，也可以和外部知识图谱协同。

### 如何评估使用 MemOS 的 ROI？

关键指标：
- Token 消耗降低（更高效）
- 输出相关性提升（更准确）
- 用户留存率提高（更理解用户）
- 知识固化率（长期沉淀多少信息）

### addMessage 后多久能检索到记忆？

- 异步模式：通常几秒到几十秒
- 同步模式：接口返回即可检索
- 多模态（文件/图片）：处理耗时较长，可通过 `get/status` 查询进度

## 错误排查

### 错误码速查表

| 错误码 | 含义 | 推荐解决方法 |
|--------|------|------------|
| **参数错误** | | |
| 40000 | 请求参数错误 | 检查参数名、类型、格式 |
| 40001 | 请求数据不存在 | 检查 memory_id / 资源 ID |
| 40002 | 必填参数不能为空 | 补充缺失字段（user_id, messages 等） |
| 40003 | 参数为空 | 检查传入的列表/对象是否为空 |
| 40010 | 用户 ID 过长 | user_id ≤ 100 字符 |
| 40011 | 会话 ID 过长 | conversation_id ≤ 100 字符 |
| 40020 | 项目 ID 非法 | 确认 Project ID 格式 |
| **认证与权限** | | |
| 40100 / 40130 | 需要 API Key 认证 | Header 添加 `Authorization: Token YOUR_KEY` |
| 40132 | API Key 无效或已过期 | 检查 Key 状态或在 Dashboard 重新生成 |
| **配额与限流** | | |
| 40300 | 超过接口调用次数上限 | 领取更多额度或升级方案 |
| 40301 | 超过请求 Token 上限 | 减少输入内容 |
| 40302 | 超过响应 Token 上限 | 缩短预期输出 |
| 40303 | 单次对话长度超限 | 缩减单次输入/输出 |
| 40304 | 账户总 API 调用次数耗尽 | 领取更多额度 |
| 40305 | 输入超过单次 Token 上限 | 拆分消息分批写入 |
| 40306 | 删除记忆鉴权失败 | 确认是否有权删除 |
| 40307 | 删除记忆不存在 | 先用 getMemory 确认 memory_id |
| 40308 | 删除记忆的用户不存在 | 检查 user_id |
| **系统与服务** | | |
| 50000 | 系统内部异常 | 稍后重试或联系支持 |
| 50004 | 记忆服务暂不可用 | 稍后重试写入/获取 |
| 50005 | 搜索服务暂不可用 | 稍后重试 searchMemory |
| 50143 | 添加记忆失败 | 算法处理异常，稍后重试 |
| 50144 | 添加消息失败 | 保存失败，稍后重试 |
| **知识库** | | |
| 50103 | 文件数量超限 | 单次 ≤ 20 文件 |
| 50104 | 单文件超限 | 单文件 ≤ 100MB |
| 50105 | 总大小超限 | 单次 ≤ 300MB |
| 50120 | 知识库不存在 | 确认 knowledgebase ID |
| 50123 | 知识库未关联项目 | 确认知识库已授权给当前项目 |

### 常见场景处理

| 错误场景 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 401 Unauthorized | API Key 无效或过期 | 检查 Authorization header 格式：`Token YOUR_KEY`；key 以 `mpg-` 开头 |
| 参数错误 | 缺少必要字段 | 确认 `user_id` 和 `conversation_id` 已提供 |
| 超限 (40305) | 单次 token 超过 40,000 | 拆分消息分批写入 |
| 检索无结果 | 记忆尚未处理完成 | 等待几秒后重试，或使用同步模式 |
| 文件处理失败 | 超过文件大小/页数限制 | 按限制要求调整后重试 |
