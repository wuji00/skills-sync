# 异步模式

控制消息写入后 MemOS 的处理时机，适应不同延迟要求的场景。

## 模式说明

通过 `addMessage` 的 `async_mode` 参数控制：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 同步 | 等待记忆处理完成后返回 | 需要立即使用新生成记忆的场景 |
| 异步（默认） | 请求立即返回，后台处理 | 大多数实时对话场景 |

## 注意

- 多模态消息（图片/文档）因处理耗时，强制使用异步模式
- 可通过 `get/status` 接口查询处理进度
- 异步模式下，新写入的记忆不会立即出现在 searchMemory 结果中，通常几秒到几十秒后可检索
