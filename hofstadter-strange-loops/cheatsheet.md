# 速查表 (Cheatsheet)

## 决策规则

| 当你看到… | 做… | 因为… |
|----------|-----|-------|
| "我" / "这里" / "现在" 这类自指词 | 标怪圈候选 | 自指 → 跨层闭环 |
| 跨领域出现"同一形状" | 抽骨架验同构 | 同构是迁移的前提 |
| 试图用系统内规则证系统一致性 | 停; 升元层 | 哥德尔禁止自指一致性 |
| 给出形式串就声称"它理解" | 问: 接地了吗? | 形式无意义, 意义由外部赋予 |
| 还原论断言 "X 完全 = Y" | 找高层因果反例 | 缠结层次是常态 |
| 在 LLM / AI 上谈"理解" | 问: 对应物何在? | 无感官 / 无行动的"理解"可疑 |
| 看到音乐 / 绘画 / 代码同形 | 用赋格卡农作类比 | 多声部 = 多推导路径 |
| 递归无终止证明 | 接受不可判定 | BlooP / FlooP / GlooP 边界 |
| 想定义"真" | 升元层 (塔斯基) | 一致系统内不可定义真 |
| 元层叠加到第 4 层以上 | 停; 复盘连接 | 元层越高与内层越脱节 |

## 怪圈识别流程

```
陈述含 "我" / "本句" / "此陈述"
    ↓
标层级: 0 (对象) → 1 (元) → 2 (元元) → ...
    ↓
构造路径: 从某层出发, 沿规则跨层
    ↓
路径回到起点?
    ├─ 是 → 怪圈 (合法)
    └─ 否 → 不是怪圈, 是普通元层
```

## 同构识别流程

```
两系统 A / B
    ↓
抽象 A 的基本元素 + 组合规则 → Skeleton_A
抽象 B 的基本元素 + 组合规则 → Skeleton_B
    ↓
找 f: A_elems → B_elems
    ↓
所有 A 上的关系 R, f(R) 都在 B 上成立?
    ├─ 是 → 同构 (保留关系)
    └─ 否 → 部分同构 (标差异)
```

## 自指构造三步

```
1. 编码: 句 → 数 (Gödel 编码, 互素数幂)
2. 自应用: 算子 diag 把数变句再变数
3. 否定自指: q = "q 不可证"
    ↓
假设系统 S 能证 q → 推出 ¬q (矛盾)
假设系统 S 能证 ¬q → 推出 q (矛盾)
    ↓
∴ q 在 S 内既不可证也不可否证
∴ S 不完备
```

## 层级分类表

| 类型 | 特征 | 典型例子 |
|------|------|---------|
| 清晰层次 | 上→下严格映射, 无回响 | 编译器分层 (近似) |
| 缠结层次 | 高低层互相渗透 | 心智 / 意识 / 语言 |
| 元层次 | 谈前一层的语言 | 元语言 / 元理论 |
| 自指层 | 谈自己 | G 句 / Quine |
| 怪圈 | 自指 + 跨层闭环 | 印刷品 / G / "我" |

## 反模式快速对照

| 反模式 | 症状 | 修正 |
|--------|------|------|
| 还原论过头 | "心 = 神经元" | 接受缠结层次 |
| 自指当 bug | 删元能力 | 保留怪圈结构 |
| 系统内看自己 | 用系统规则证一致性 | 升元层 |
| 形式化一切 | 想把"真"塞进系统 | 留系统外直觉 |
| 误用芝诺 | 把无限步当永恒 | 接受可数无限 |
| 元语言过载 | 多层混乱 | 显式标层级 |

## 应用示例

**场景 1**: 写 LLM 评估框架, 问"它真的懂了吗?"
1. 形式层: 输出对提示的应答 (字符串)
2. 接地层: 是否有外部感官 / 行动 / 因果对应?
3. 若无 → 标"未接地" — 输出再流畅也不算懂

**场景 2**: 设计自描述系统 (配置系统能报告自己的配置)
1. 形式层: 配置文件 + 读取器
2. 自指层: 配置文件引用读取器; 读取器读自己
3. 闭环检测: 是否陷入"配置改了, 读取器也得改" 无限循环?
4. 若无限 → 升元层, 把"读取器"作为外部固定点

**场景 3**: 调 Bug, 发现循环依赖
1. 标依赖图
2. 找闭环
3. 闭环 = 怪圈候选
4. 是否跨层 (软件层 ↔ 配置层 ↔ 部署层)? 若是, 重新评估"清晰层次"假设

## 关键数与限制

- 哥德尔 (1931): 算术系统必不完备
- 图灵 (1936): 停机问题不可判定
- 塔斯基 (1933): 真理不可在系统内定义
- 丘奇 (1936): λ 演算与图灵机等价
- 巴赫: 《音乐的奉献》(1747), 六部无插入赋格
- 艾舍尔: 《画廊》(1956), 《瀑布》(1961), 《上升与下降》(1960)
