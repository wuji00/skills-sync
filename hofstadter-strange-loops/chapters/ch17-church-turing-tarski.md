# 第十七章: 丘奇、图灵、塔斯基及别的⼈

**Part**: 下篇 | **Type**: chapter

## Core Idea
丘奇-图灵论题 + 塔斯基真理不可定义性 — 计算与真理的边界。

## Frameworks Introduced
- **丘奇-图灵论题**: 可计算函数 = 递归函数 = λ 可定义 = 图灵机可计算 — 全部等价。
- **塔斯基不可定义真理性**: 在一个足够强的语言内, 真理谓词不可定义。

## Key Concepts
- **丘奇 (Alonzo Church)**
- **图灵 (Alan Turing)**
- **塔斯基 (Alfred Tarski)**
- **λ 演算**
- **真理谓词**
- **对角线法**

## Mental Models
- Use 丘奇-图灵论题 when 评估'可计算'概念 — 用任一种精化定义。
- Use 塔斯基不可定义真理性 when 评估'真可在系统内定义'断言。

## Anti-patterns
- ("把'真'当可形式化", '以为真理谓词可在系统内定义 — 实际不行 (塔斯基)。')
- ("把'可计算'当直觉", "以为'能写出来的就是可计算' — 实际有精确定义 (丘奇-图灵)。")

## Worked Example
丘奇-图灵论题:
- 递归函数 (Gödel 1931)
- λ 可定义 (Church 1936)
- 图灵机 (Turing 1936)
- 后寄存器机 / 流程图 / 现代编程语言 (只要图灵完备)

全部等价 — 这是可计算性的'自然种类'。

塔斯基真理不可定义性:
1. 设 L 是足够强的语言 (能表达算术)。
2. 设 T 是 L 中的真理谓词, 即 T(x) 当且仅当 x 是 L 中的真句。
3. 构造 '克里特岛人' 句: K = 'K 在 L 中不是真的'
4. 假设 T(K) → K 真 → K 内容 'K 不是真' → K 不是真 → T(K) 矛盾
5. 假设 ¬T(K) → K 不是真 → K 内容 'K 不是真' → K 内容真 → T(K) 矛盾
6. ∴ L 中无真理谓词

## Key Takeaways
1. 可计算性有精确定义 (丘奇-图灵) — 不只是直觉。
1. 真理不可在系统内定义 (塔斯基) — 这是哥德尔定理的'真理版本'。
1. 对角线法是统一的不可判定性证明工具。
