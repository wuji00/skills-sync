# 第十二章: 心智和思维

**Part**: 下篇 | **Type**: chapter

## Core Idea
心智即'软件'; 亚符号 / 符号并行; 心智是'模式'而非'符号'。

## Frameworks Introduced
- **心智即软件**: 心智是'程序', 大脑是'硬件'。
- **亚符号 + 符号并行**: 心智同时有'数字信号层' (神经元) 和'符号层' (概念)。

## Key Concepts
- **心智即软件**
- **亚符号 (Sub-symbolic)**
- **符号 (Symbolic)**
- **并行处理**
- **概念 (Concept)**

## Mental Models
- Use 心智即软件 when 想用工程语言理解心智 — 不要纠缠硬件细节。
- Use 亚符号 + 符号并行 when 想解决符号接地 — 不要把心智当纯符号系统。

## Anti-patterns
- ('纯符号心智', '以为心智只是符号推理 — 实际是符号 + 亚符号并行。')
- ('纯联结心智', '以为心智只是神经元活动 — 实际需要符号层。')

## Worked Example
侯世达立场: 心智是软件, 但不是'纯符号软件'。LLM 类比: 当前 LLM 是'纯符号' (Token 序列), 但心智需要亚符号层 (感官输入、行动输出)。这是符号接地问题: 纯符号系统没有'对应物', 心智必须有对应物。

## Key Takeaways
1. 心智是软件, 但需要硬件 (大脑) + 对应物 (感官 / 行动)。
1. 纯符号系统 (如 LLM) 没有接地, 不能算'理解'。
1. 亚符号 + 符号并行是心智的标准模型。
