# 第五章: 递归结构和递归过程

**Part**: 上篇 | **Type**: chapter

## Core Idea
递归 = 自己定义自己; 卡农 + 图灵机 + DNA 自复制同构。

## Frameworks Introduced
- **递归 (Recursion)**: 在定义中调用自己; 必须有终止条件或可证终止。
- **递归跳转 (Recursive Jump)**: 在递归定义中'跳'到自己 — 对应形式系统跨层。
- **同构 (Isomorphism)**: 卡农 ≡ 图灵机 ≡ DNA 自复制 — 同形异载。

## Key Concepts
- **递归**
- **递归跳转**
- **卡农**
- **图灵机**
- **DNA 自复制**
- **丘奇-图灵论题**

## Mental Models
- Use 递归当通用模板 when 任何'自己定义自己'的现象。
- Use 递归跳转 when 跨层推理。
- Use 卡农/图灵机/DNA 同构 when 演示'同形异载'。

## Anti-patterns
- ('无终止条件递归', '递归没基础情形 — 死循环。')
- ('跨层无标记', '递归跳转不显式标 — 读者/代码都迷失。')

## Worked Example
卡农: 一声部主题 + 一延时复制。
图灵机: 当前状态 + 当前符号 → 新状态 + 新符号 + 移动。
DNA 自复制: 双螺旋解开 + 每链作模板 → 两新双螺旋。

抽象骨架: {主体 + 模式 + 复制指令}。三者同构:
- 主体 = 卡农主旋律 / 图灵机带 / DNA 单链
- 模式 = 延时复制 / 状态转换 / 碱基配对
- 复制指令 = 演奏规则 / 转移函数 / 聚合酶

差异: 卡农有'听众', 图灵机没有; DNA 有'物理基底', 卡农没有 — 但骨架同。

## Key Takeaways
1. 递归是普遍模式 — 音乐 / 数学 / 生物 / 程序。
1. 递归跳转是跨层工具, 不是错误。
1. 同构识别需要严格保留关系, 不能凭直觉。
