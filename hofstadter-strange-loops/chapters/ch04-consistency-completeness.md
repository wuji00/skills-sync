# 第四章: 一致性、完全性与几何学

**Part**: 上篇 | **Type**: chapter

## Core Idea
哥德尔定理的预备: 一致 vs 完全; 几何对应物 — 尺规作图不可做到的事。

## Frameworks Introduced
- **一致性 (Consistency)**: 系统不同时证 P 与 ¬P。
- **完全性 (Completeness)**: 每个真命题都可证 (此处指算术系统)。
- **几何对应物**: 几何'三等分角不可尺规作图'对应'算术系统必不完备'。

## Key Concepts
- **一致性**
- **完全性**
- **几何**
- **尺规作图**
- **三等分角**
- **倍立方**
- **化圆为方**

## Mental Models
- Use 一致性 / 完全性区分 when 评估形式系统的局限 — 两者常常不可兼得。
- Use 几何对应物 when 想让抽象定理直观 — 找'不可能的几何操作'作类比。

## Anti-patterns
- ('把完全性当绝对', "期望任何系统都'完全' — 哥德尔证明此期望必落空。")
- ('把一致性当可证', '试图用系统内规则证自己一致 — 哥德尔禁止。')

## Worked Example
几何三大尺规不可解: 三等分角 / 倍立方 / 化圆为方。每一对应代数上一类方程无根式解。算术系统的不完备性对应: 不是'某些定理不可证', 而是'存在真命题不可证'。两类'不可能'同构: 都不是证明力不够, 是对象本身的性质。

## Key Takeaways
1. 形式系统的一致性和完全性不可兼得 (对足够强的系统)。
1. 几何的'不可作图'对应算术的'不可证' — 同形异载的实例。
1. 哥德尔定理前的预备: 接受形式系统有边界。
