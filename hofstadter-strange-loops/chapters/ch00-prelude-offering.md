# 导言: 一首音乐—逻辑的奉献

**Part**: 上篇 | **Type**: prelude

## Core Idea
全书导言; 三主题 (巴赫/艾舍尔/哥德尔) 首次交汇; 解释为何用对话体承载论证。

## Frameworks Introduced
- **元音乐的奉献**: 整本书是对《音乐的奉献》故事的'即兴演出'。
- **三主题同构**: 巴赫的对位 / 艾舍尔的视觉悖论 / 哥德尔的形式自指 — 同形异载。

## Key Concepts
- **对位藏头诗 (Acrostic Dialogue)**
- **元 (Meta)**
- **自指**
- **同构 (Isomorphism)**
- **巴赫《音乐的奉献》**
- **即兴演奏**

## Mental Models
- Use 元结构 when 把一本书的整体当一次即兴演奏 — 即兴不是乱, 是'按主题变形'。
- Use 三主题并置 when 想展示'同形异载' — 用同一抽象串接三领域。

## Anti-patterns
- ('单主题独白', '一本书只讲一个领域, 看不到跨域同形。')

## Worked Example
侯世达给腓德烈王的故事: 巴赫当场即兴演奏《音乐的奉献》。本书就是侯世达对'对位 / 视觉 / 自指'三主题的'元即兴'。

## Key Takeaways
1. 全书的统一隐喻是'即兴' — 不是任意, 是按主题的变形。
1. 三主题并置不是并列, 是同构的不同载体。
1. 用对话体 (而非论文体) 是为了把硬论证包装得可读。
1. 本书是元书 — 它在讲'自指', 同时演示自指。
