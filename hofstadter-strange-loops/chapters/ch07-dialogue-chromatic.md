# 对话 7: 半音阶幻想曲, 及互格

**Part**: 上篇 | **Type**: dialogue

## Core Idea
半音变形 = 元层跃迁; 同一主题, 每次变形 = 升一层。

## Frameworks Introduced
- **半音变形作为元层**: 音程每次半音阶移动 = 主题在元层变一次。

## Key Concepts
- **半音阶 (Chromatic)**
- **互格 (Double Fugue)**
- **元层跃迁**

## Mental Models
- Use 半音变形 when 演示'同一抽象在不同层' — 音程差 = 元层距离。

## Anti-patterns
- ('同层变形', "以为主题变形是'同一层' — 实际是元层跃迁。")

## Worked Example
半音阶幻想曲: 主题每次半音上升 = 升一个元层。本对话用此演示'G 句的构造过程'的预演 — 主题每半音上升 = 加一层引用。

## Key Takeaways
1. 音乐变形可作为元层跃迁的隐喻。
1. 同主题的不同变形 = 同抽象的不同层。
