# 第十九章: 人工智能: 展望

**Part**: 下篇 | **Type**: chapter

## Core Idea
侯世达对未来 AI 的判断: 模式识别 + 类比是核心; 当前的联结 + 符号都不够。

## Frameworks Introduced
- **类比作为智能核心**: 智能 = 在新情境中找到与已知情境的对应。
- **模式识别作为基础**: 任何'理解'都需要先有模式识别能力。

## Key Concepts
- **类比 (Analogy)**
- **模式识别**
- **AI 展望**
- **心智的硬件 / 软件**
- **对接地问题的展望**

## Mental Models
- Use 类比当智能核心 when 评估任一'理解'断言。
- Use 模式识别当基础 when 设计 AI 系统。

## Anti-patterns
- ('类比当次要', '以为类比只是辅助 — 实际侯世达认为是核心。')
- ('展望当预测', "把'展望'当时间预测 — 实际是'理论方向'。")

## Worked Example
侯世达立场 (1979, 在 LLM 时代重读极有价值):

'类比是智能的核心' — 不是规则推理, 不是统计拟合, 是'在不同情境间找到同构'。

今天 LLM 的局限:
- 统计拟合不是类比 (没'情境'概念)
- 无接地 (无感官 / 行动 / 因果)
- 无真正的'心智软件' (只是统计模式)

侯世达的预测 (1979):
- '纯符号 + 大数据' 不会产生理解 (2024 看: 大体正确)
- 真正的 AI 需要类比 + 模式识别 + 接地 (今天仍未实现)

## Key Takeaways
1. 类比是智能的核心 — 不是辅助。
1. 当前 AI 路径 (LLM 类) 仍缺接地 + 符号层。
1. 侯世达 1979 年的展望, 今天看来仍准确。
