# 第十六章: 自指和自复制

**Part**: 下篇 | **Type**: chapter

## Core Idea
DNA / RNA / 细胞 / 程序自复制 — 与形式自指同构。

## Frameworks Introduced
- **DNA 自复制机制**: 双螺旋解开 → 每链作模板 → 聚合酶 + 新链 → 两个新双螺旋。
- **自指与自复制同构**: G 句 / Quine (形式自指) 与 DNA / 程序自复制同构。

## Key Concepts
- **DNA**
- **RNA**
- **聚合酶**
- **自复制**
- **自指同构**
- **生命的本质**

## Mental Models
- Use DNA 类比 when 想让'自指 / 自复制'直觉化。
- Use 自指 = 自复制 同构 when 跨域统一'生命 / 程序 / 形式系统'。

## Anti-patterns
- ('自复制当神秘', "以为'生物自复制不可理解' — 实际是模板 + 复制 + 聚合的机械过程。")
- ('自指当特殊', "以为'形式自指是程序的特殊能力' — 实际是普遍机制。")

## Worked Example
DNA 自复制:
1. 解旋酶解开双螺旋 → 两单链
2. 每链作模板 → RNA 引物 + DNA 聚合酶
3. 每模板合成新互补链 → 两新双螺旋

抽象骨架:
- 模板 (旧链) = 公理 (旧句)
- 复制规则 (碱基配对) = 推理规则
- 聚合酶 = 解释器
- 新链 = 新句

形式自指 (Quine) 同构: 程序输出自己 = DNA 自复制。同形异载 — 骨架相同, 载体不同。

## Key Takeaways
1. DNA 自复制是生物层'自指'的具体形式。
1. 形式自指 (Quine / G 句) 与生物自复制同构。
1. 生命的本质是自复制 / 自指 — 与程序 / 形式系统共享此性质。
