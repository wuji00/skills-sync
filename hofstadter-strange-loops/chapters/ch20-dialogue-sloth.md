# 对话 19: 树懒卡农

**Part**: 下篇 | **Type**: dialogue

## Core Idea
极慢 + 主题增殖; 对应'深度推理'需要时间 + 多主题。

## Frameworks Introduced
- **极慢对应深度推理**: 树懒的极慢 = 深度推理的'每步必思'。
- **主题增殖**: 原主题每次增值 + 衍生新主题 — 对应'推理展开 + 发现新结构'。

## Key Concepts
- **树懒卡农 (Sloth Canon)**
- **深度推理**
- **主题增殖**

## Mental Models
- Use 树懒类比 when 想演示'深度推理需要时间'。
- Use 主题增殖 when 想演示'推理展开 + 新结构涌现'。

## Anti-patterns
- ('快 = 浅', '快速推理 = 浅推理 — 实际可以又快又深, 但需要基础。')

## Worked Example
巴赫的树懒卡农: 极慢速度 + 主题在每次增值中衍生新材料。本对话中, 阿基里斯 + 乌龟讨论'为何重要发现需要时间?' — 因为重要发现 = 主题 + 衍生主题 + 衍生主题… 过程慢, 但产物多。

## Key Takeaways
1. 深度推理需要时间 — 不必快。
1. 重要发现 = 主题 + 多衍生主题。
1. 树懒卡农是'深度推理'的音乐版本。
