# 第一章: WU 谜题

**Part**: 上篇 | **Type**: chapter

## Core Idea
用最简单的形式系统 WJU 引入'系统内 / 系统外'视角的差别。

## Frameworks Introduced
- **形式系统 (Formal System)**: 公理 + 推理规则; 完全自足, 不依赖意义。
- **判定过程 (Decision Procedure)**: 算法可在有限步内判断任意串是否为定理。
- **内部视角 vs 外部视角**: 在系统内推 vs 在系统外审视系统本身 — 哥德尔定理的关键。

## Key Concepts
- **WJU 系统**
- **公理**
- **推理规则**
- **推导 (Derivation)**
- **定理**
- **系统外观察者**

## Mental Models
- Use 系统内 / 系统外区分 when 评估论证有效性 — 是用系统内规则, 还是系统外直觉?
- Use 判定过程存在性 when 评估'形式化是否完备'。

## Anti-patterns
- ('把形式系统当推理', "系统内推到结论 ≠ 系统有'推理能力'; 系统只是规则机器。")

## Worked Example
WJU 系统:
- 符号: W, J, U
- 公理: WJU
- 规则 1: xJ → xJU (任何以 J 结尾的串可加 U)
- 规则 2: xW → xWJ (任何以 W 结尾的串可加 J)
- 规则 3: JUU → 空 (此规则不可逆)
- 问题: 从 WJU 出发, 是否可推出 U?
答案: 否 — 任何推导出的串, J 的个数必为 2 的幂加 1 (起始 WJU 有 1 个 J); U 中 J 个数为 0, 不符合。

外部视角关键: 系统内的'不可达'是形式事实, 不依赖意义。

## Key Takeaways
1. 形式系统的定理性是机械事实, 不是逻辑必然。
1. 外部视角能看到内部看不到的全局模式 (如 J 的幂律)。
1. WU 谜题本身不难, 难的是体会'系统外看系统'的姿态。
