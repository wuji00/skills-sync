# 第七章: 命题演算

**Part**: 上篇 | **Type**: chapter

## Core Idea
形式逻辑的基础; 推理规则 + 公理; 与日常语言的精确化对应。

## Frameworks Introduced
- **命题演算 (Propositional Calculus)**: 由命题 + 连接词 + 推理规则组成的逻辑系统。
- **推理规则的合法性**: 推理规则保持真值: 若前提真, 结论必真。

## Key Concepts
- **命题**
- **连接词**
- **推理规则**
- **公理**
- **定理**
- **有效性**
- **完备性**

## Mental Models
- Use 命题演算当基本工具 when 任何'如果…那么…'链。
- Use 推理规则合法性 when 评估论证 — 任何'前提 → 结论'都可形式化验证。

## Anti-patterns
- ('自然语言推理当形式', "日常'显然''所以'等不能保证有效 — 必须形式化。")
- ('混淆有效与真', '有效论证可能从假前提出真结论 — 有效 ≠ 真。')

## Worked Example
标准命题演算:
- 连接词: ¬, ∧, ∨, →
- 公理: (P → (Q → P)), ((P → (Q → R)) → ((P → Q) → (P → R))), 等等
- 推理规则: 肯定前件 (P, P → Q ⊢ Q)

任何'如果天下雨, 那么地面湿。今天天下雨。所以地面湿'可形式化为 P → Q, P ⊢ Q。这是有效论证。

## Key Takeaways
1. 命题演算是形式化的'最低公约数'; 任何逻辑链都应能形式化。
1. 有效 ≠ 真 — 有效论证的结论可能为假, 但'若前提真, 结论必真'。
1. 哥德尔定理后续章节中, 命题演算的'一致性 + 完全性'将让位给算术的'一致性 ≠ 完全性'。
