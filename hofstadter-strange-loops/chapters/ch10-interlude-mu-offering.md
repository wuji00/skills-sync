# 间奏: 一首无的奉献 (A Mu Offering)

**Part**: 间奏 | **Type**: interlude

## Core Idea
上篇与下篇之间的间奏; 用 MU 主题 + 怪圈 + 禅宗三主题汇合。

## Frameworks Introduced
- **间奏作为汇总**: 在上下篇之间, 用一个独立作品汇合已展开的主题。

## Key Concepts
- **间奏 (Interlude)**
- **赋格 + 卡农 + 主题变形**
- **主题汇合**

## Mental Models
- Use 间奏作为汇总 when 长作品需要'主题回归 + 变奏'。

## Anti-patterns
- ('间奏当无关小品', '间奏没承担主题 — 失去结构功能。')

## Worked Example
巴赫《音乐的奉献》中的《一首无的奉献》是上篇结尾 + 间奏的对应物; 它包含多个变奏, 主题在每次变奏中变形, 但始终可识别。本间奏中, 侯世达把 MU / 怪圈 / 禅宗三个主题并置, 让读者在读下篇前先消化三主题的汇合。

## Key Takeaways
1. 间奏的功能是汇合 + 喘息, 不是空白。
1. 好的间奏会让读者重新审视已读过的主题。
1. 主题的'变形但可识别'是间奏成功的标志。
