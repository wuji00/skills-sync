# 第三章: 图形与衬底

**Part**: 上篇 | **Type**: chapter

## Core Idea
艾舍尔的视觉悖论; 层次不是中性容器, 而是观察者的视角产物。

## Frameworks Introduced
- **图形 vs 后景 (Figure vs Ground)**: 同一视觉场可有多种'前景 / 背景'切分。
- **Escher 的层次游戏**: 艾舍尔用版画演示'同一画面, 多种层次解读'。

## Key Concepts
- **艾舍尔 (M.C. Escher)**
- **画廊 (Print Gallery)**
- **瀑布 (Waterfall)**
- **上升与下降 (Ascending and Descending)**
- **前景 / 后景**

## Mental Models
- Use 视角切分 when 评估'某层是某层的属性' — 问: 切分是否绝对? 是否有反例视角?
- Use Escher 案例 when 教学'层次是相对的'。

## Anti-patterns
- ('层次绝对论', "'硬件层独立于应用层' — 在实际系统中, 反例很多。")

## Worked Example
《画廊》: 中心空白 → 空白里有画廊 → 画廊里有看画的人 → 看画的人在看画 → 无限缩进。看似悖论, 实际是合法的层级跨步。读者以为'画是闭合的', 实际画中心指向'画自己'。

## Key Takeaways
1. 层次不是物本身, 是观察者的视角切分。
1. 艾舍尔的版画是怪圈的视觉原型 — 不是 bug, 是合法的跨层闭环。
1. 同一'画'可有多种'层次解读' — 解读之间是同构关系。
