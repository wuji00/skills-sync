# 第十八章: 人工智能: 回顾

**Part**: 下篇 | **Type**: chapter

## Core Idea
早期 AI 流派 (符号 / 联结 / 演化); 侯世达的批评: 都缺'模式识别 / 接地'。

## Frameworks Introduced
- **符号 AI**: 心智 = 符号操作; 推理 = 形式推理。
- **联结 AI**: 心智 = 神经元网络; 推理 = 模式激活。
- **演化 AI**: 心智 = 进化结果; 推理 = 优胜劣汰。

## Key Concepts
- **符号 AI**
- **联结 AI**
- **演化 AI**
- **模式识别**
- **符号接地问题**
- **AI 历史**

## Mental Models
- Use 三流派分类 when 评估 AI 路径。
- Use 侯世达批评 when 评估任一 AI 主张。

## Anti-patterns
- ('符号 AI 当万能', "以为符号推理就是智能 — 实际缺'接地'。")
- ('联结 AI 当万能', "以为神经网络就是智能 — 实际缺'符号层'。")
- ('演化 AI 当万能', "以为进化就是智能 — 实际缺'个体心智'。")

## Worked Example
侯世达 1979 年立场 (回顾今天 LLM):
- 符号 AI: 缺乏接地 — 纯符号操作没有'对应物'
- 联结 AI: 缺乏符号层 — 网络权重不构成概念
- 演化 AI: 缺乏个体心智 — 进化论不解释个体思维

LLM 类比: 当前 LLM 是'大型符号统计系统' — 介于符号 AI 与联结 AI 之间。但仍缺'接地' (无感官 / 无行动) 与'符号层' (Token 序列不构成概念)。

## Key Takeaways
1. 三流派都有局限 — 没有'完全 AI'路径。
1. 侯世达批评的核心: 缺'模式识别 + 接地'。
1. 今天 LLM 也未能完全克服这些局限。
