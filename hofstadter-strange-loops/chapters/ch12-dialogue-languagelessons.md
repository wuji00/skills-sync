# 对话 11: 英、法、德、中组曲

**Part**: 下篇 | **Type**: dialogue

## Core Idea
同一内容, 多种语言表达; 对应'同一心智模式, 多层表示'。

## Frameworks Introduced
- **多语言对应多表示层**: 同一信息, 多语言 = 多表示层; 翻译保留'模式'但形式变。

## Key Concepts
- **多语言**
- **翻译**
- **跨层表示**
- **模式 vs 形式**

## Mental Models
- Use 多语言类比 when 想说明'同一抽象, 多形式表达'。

## Anti-patterns
- ('语言 = 思维', '以为某语言决定某思维 — 实际语言只是表示, 思维在更深处。')

## Worked Example
'我爱你' / 'I love you' / 'Je t'aime' / 'Ich liebe dich' — 四种语言, 同一信息。多语言组曲演示: 翻译不丢'信息', 但各语言的语法 / 习惯不同。这是心智多层表示的对应物: 同一'思维内容', 不同表示层 (语言 / 图像 / 行动)。

## Key Takeaways
1. 语言是表示, 不是思维本身。
1. 同一思维可有多种表示 — 翻译的可行性基于此。
1. 多语言组曲是'跨层表示'的演示。
