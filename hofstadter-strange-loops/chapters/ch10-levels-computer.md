# 第十章: 描述的层次和计算机系统

**Part**: 下篇 | **Type**: chapter

## Core Idea
计算机系统的层次; 自描述程序作为反向应用哥德尔。

## Frameworks Introduced
- **层次 (Levels)**: 硬件 / 微码 / 机器语言 / 汇编 / 高级语言 / 应用 — 多层。
- **自描述程序 (Self-Describing Program)**: 程序能输出自己的源代码; 同构 G 句。

## Key Concepts
- **层次**
- **编译器**
- **解释器**
- **自描述程序**
- **Quine**
- **哥德尔反向应用**

## Mental Models
- Use 层次当通用分析框架 when 处理复杂系统。
- Use 自描述程序 when 演示'代码看到自己'。

## Anti-patterns
- ('层次绝对化', '假设硬件层与应用层无回响 — 实际有反馈 (硬件改驱动)。')
- ('自描述当噱头', "Quine 没用 — 实际它是'自指'的最小可用形式。")

## Worked Example
Quine 例 (Python):
```python
s = 's = %r\nprint(s %% s)'
print(s % s)
```
运行此代码, 输出仍是此代码。这是 G 句的程序版本 — 系统能指向自己。

反向应用哥德尔: 不是'系统不可证自己' (G 句), 而是'系统能输出自己' (Quine)。这是同构的'积极面'。

## Key Takeaways
1. 计算机系统的层次是清晰的; 但层间有反馈, 不是绝对分离。
1. Quine 是自指的工程版本 — 实际应用包括自包含程序、测试代码、病毒等。
1. 哥德尔定理的'反面': 系统能描述自己 — 这是反向工程的能力。
