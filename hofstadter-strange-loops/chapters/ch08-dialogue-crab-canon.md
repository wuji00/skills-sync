# 对话 8: 螃蟹卡农

**Part**: 上篇 | **Type**: dialogue

## Core Idea
螃蟹卡农 = 倒行卡农; 对应对偶 / 否定操作。

## Frameworks Introduced
- **倒行作为对偶**: 主题正行 + 倒行同时 = 正命题 + 对偶命题。

## Key Concepts
- **螃蟹卡农 (Crab Canon)**
- **倒行 (Retrograde)**
- **对偶 (Dual)**

## Mental Models
- Use 螃蟹卡农 when 演示'对偶命题' — 倒行 = 否定 / 对偶。

## Anti-patterns
- ('单方向陈述', '只讲正命题, 不讲对偶 — 失去对照面。')

## Worked Example
巴赫的螃蟹卡农: 主题正向演奏 + 同时倒行。两者同步结束。本对话中, 阿基里斯 + 乌龟一个说正话, 一个同时说反话 — 听起来像一首诗, 但实际是两套完全对立的陈述。这是哥德尔定理的预演: 任意串 + 其否定, 在系统内的命运。

## Key Takeaways
1. 螃蟹卡农是'对立命题并存'的音乐版本。
1. 对偶 / 否定是形式系统的核心结构 — 不能忽视。
