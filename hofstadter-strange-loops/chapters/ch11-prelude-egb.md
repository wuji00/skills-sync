# 下篇前奏: 前奏曲

**Part**: 下篇 | **Type**: prelude

## Core Idea
下篇 EGB 开始; 主题从'符号如何指向自身'转向'符号如何指向世界'。

## Frameworks Introduced
- **下篇主题转向**: 从'自指' (上篇) 到'指向世界' (下篇)。

## Key Concepts
- **下篇**
- **EGB**
- **指向世界 (Reference)**
- **符号接地预备**

## Mental Models
- Use 主题转向 when 长作品需要阶段演化 — 不必每章都重复同一主题。

## Anti-patterns
- ('前后篇断裂', '上篇和下篇无连接 — 失去整体感。')

## Worked Example
前奏曲的经典功能: 预告即将展开的主题。本前奏预告: 心智 / 大脑 / 思维 / 形式系统的'指向世界'问题 — 与上篇'系统内自指'对照。

## Key Takeaways
1. 下篇的转向: 从'自指'到'指向世界'。
1. 前奏曲是过渡, 不可当独立章节。
1. 上下篇需有'主题接缝', 不能断裂。
