# 对话 16: 的确该赞美螃蟹

**Part**: 下篇 | **Type**: dialogue

## Core Idea
螃蟹卡农的回声; 用'倒行'结构总结自指 + 对偶。

## Frameworks Introduced
- **回声式对话**: 在主题展开多次后, 用简短对话'回声'主题。

## Key Concepts
- **螃蟹卡农回声**
- **对偶**
- **自指总结**

## Mental Models
- Use 回声式对话 when 长作品需要主题回顾。

## Anti-patterns
- ('回声当冗余', "重复前面的内容 — 实际是'不同视角'的回声。")

## Worked Example
本对话中, 阿基里斯 + 乌龟 + 螃蟹 + 甲虫讨论'为何赞美螃蟹?' — 因为螃蟹卡农是'倒行' = 对偶 = 自指 + 否定。这是第 8 章螃蟹卡农的回声, 也是 17 章塔斯基不可定义真理性的预备。

## Key Takeaways
1. 回声式对话是对前面主题的'不同视角回顾'。
1. 螃蟹卡农的'倒行'是'对偶 / 否定'的隐喻。
