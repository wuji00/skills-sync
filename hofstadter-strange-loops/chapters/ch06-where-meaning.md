# 第六章: 意义位于何处

**Part**: 上篇 | **Type**: chapter

## Core Idea
形式系统内部无意义; 意义在系统外的解释者; 艾舍尔式的意义跨层。

## Frameworks Introduced
- **意义 = 解释者映射**: 意义是'外部观察者'给形式串的对应物。
- **多层意义 (Levels of Meaning)**: 一句话可有语法 / 语义 / 语用三层。

## Key Concepts
- **意义 (Meaning)**
- **解释 (Interpretation)**
- **对应物 (Referent)**
- **语用**
- **接地 (Grounding)**

## Mental Models
- Use 意义 = 映射 when 评估任何'X 含义 Y'的断言。
- Use 三层意义 when 处理自然语言 / 多义术语。

## Anti-patterns
- ('形式串 = 意义', '以为写得形式化就有意义 — 形式只是符号, 意义是映射。')
- ('单层意义假设', '假设一个词只有一个含义 — 自然语言普遍多层。')

## Worked Example
例: '猫在垫子上'。
- 语法层: 主语 + 介词短语
- 语义层: 实际指一只特定的猫 + 特定的垫子
- 语用层: 这只猫在休息 (隐性前提)

形式化能讲清语法; 语义需要外部观察者; 语用需要语境。三层不可全形式化 — 这是符号接地的核心限制。

## Key Takeaways
1. 意义是观察者赋予的, 不是符号固有的。
1. 形式系统能讲清语法, 但语义和语用必须靠系统外。
1. 符号接地问题是 AI 的核心限制 — LLM 也未能完全解决。
