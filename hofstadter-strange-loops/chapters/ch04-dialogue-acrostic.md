# 对话 4: 对位藏头诗

**Part**: 上篇 | **Type**: dialogue

## Core Idea
用'字母层对位'承载哲学论证; 藏头诗本身就是同构的视觉对应物。

## Frameworks Introduced
- **多声部对位**: 多声部同时陈述 + 变形; 对应多推导路径并行。

## Key Concepts
- **对位藏头诗 (Acrostic)**
- **藏头**
- **声部 (Voice)**
- **同步**

## Mental Models
- Use 多声部对位 when 想让读者直觉地看到'并行推导'。

## Anti-patterns
- ('单声部独白', '只讲一种视角 — 失去同构的对照面。')

## Worked Example
巴赫写过藏头诗式的对位作品; 本对话是侯世达写的'藏头' — 字母层的排列对应声部层的排列。读者若把每行第一个字母读出, 会发现隐藏的信息。

## Key Takeaways
1. 对位不只在音乐中; 任何多视角同时陈述都是对位。
1. 藏头诗式的'层间对应'是同构的文学版本。
