# 词汇表 (Glossary)

按字母 / 拼音排序。引用形式: (Ch N) 指章号, (对话) 指对话体。

---

**AI / 人工智能** — 侯世达对 AI 的判断贯穿 ch18-19: 反对纯符号 / 纯联结, 主张"心智是软件"。 (ch18, ch19)

**阿基里斯 (Achilles)** — 对话主角之一; 来自芝诺悖论中的快脚英雄; 永远追不上乌龟但实际追上 — 芝诺式悖论的化身。(贯穿全部对话)

**埃舍尔 (Escher / M.C. Escher)** — 荷兰版画家; 侯世达大量引用其作品作怪圈 / 自指 / 层次互渗的视觉样本 — 《瀑布》《上升与下降》《画廊》《昼与夜》。 (ch03, ch04, ch05, ch10, ch16, ch20)

**BlooP** — 可证明终止的程序语言; 表达原始递归函数。 (ch13)

**BlooP / FlooP / GlooP** — 三层可计算性: BlooP = 可证终止; FlooP = 可能不终止; GlooP = 不可判定。 (ch13)

**不 / 不可判定 (Undecidable)** — 在一致形式系统内既不可证也不可否证的命题。 (ch09, ch13, ch14, ch17)

**缠结的层次结构 (Tangled Hierarchy)** — 层级相互渗透, 不存在严格元语言; 与"清晰层次"对立。 (ch10, ch12, ch20)

**层次 (Hierarchy / Levels)** — 系统的多层结构; 侯世达区分"清晰" vs "缠结"两种。 (贯穿全书, ch20 集中)

**尺规作图 (Compass-and-Straightedge)** — 几何构造受限情形; 对应"形式系统内可构造的子集"。 (ch04)

**触发词 / 三部创意曲** — 巴赫三声部对位作品; 用作全书"多声部主题对位"的隐喻。 (对1, 全书)

**Dialogue / 对话体** — 用角色对话承载哲学论证; 乌龟、阿基里斯、螃蟹、甲虫为主。 (19 篇对话贯穿)

**FlooP** — 包含 WHILE 循环、可能不终止的程序语言; 表达所有图灵可计算函数。 (ch13)

**G 句 (Gödel Sentence)** — 在系统内表述自身不可证的命题; 通过对角线构造。 (ch09, ch14)

**GlooP** — 与图灵机等价, 包含不可判定问题 (停机) 的语言。 (ch13)

**Gödel / 哥德尔** — 库尔特·哥德尔; 1931 年证明算术系统不完备性; 本书核心。 (ch04, ch08, ch09, ch14, ch17)

**怪圈 (Strange Loop)** — 跨层路径的闭环; 看似死循环实为合法跨层。 (ch03, ch09, ch14, ch15, ch20)

**罐头 (Can) / 番茄** — 伍迪·艾伦式; 龟/阿基里斯对话中调侃罐头 + 番茄 = "番茄罐装食品"。 (对话体常用笑点)

**蝴蝶 (Crab Canon)** — 螃蟹卡农 — 倒行; 对话 8, 16 引用。 (对8, 对16)

**回应 / 应答 (Answer / Subject)** — 赋格中主题被另一声部在不同音高上重复; 对应形式系统的引用规则。 (贯穿)

**J / 元语言跳跃** — 从对象语言升到元语言; 一旦上去就不能用同种规则回去。 (ch09, ch15)

**机器学习** — 不在 1979 年原书; 但可对照 ch18-19 反思"模式拟合 vs 心智"。 (ch18, ch19)

**计算机程序作为自指 / Quine** — 自输出源代码的程序; 与 G 句同构。 (ch14, ch16)

**加法 / 乘法 (Add / Mul)** — TNT 中的基本算术; 字符串形式定义。 (ch08)

**见实 / 对实 (Contrafactum)** — 主题整体反向后重写; 对话 18。 (对18)

**借记 / 贷记** — 形式系统的"账本" — 每步推出记为一行。 (ch01)

**句法 (Syntax)** — 形式系统的符号层; 与语义对。 (贯穿)

**卡农 (Canon)** — 一声部主题 + 另一声部延时重复; 对应程序调用自身。 (ch05, 对6, 对8)

**蚂蚁赋格 (Ant Fugue)** — 蚂蚁沿纸面爬行, 局部视野 vs 全局赋格; 视角依赖。 (对10)

**莱布尼茨 (Leibniz)** — 提到"一切皆计算"的先驱思想; 本书哲学背景之一。 (ch07, ch17)

**六部无插入赋格 (6-Part Ricercar)** — 巴赫《音乐的奉献》终曲; 全书结尾对话。 (对20)

**M.C. 埃舍尔** — 同"埃舍尔"。 (各处)

**Meta / 元** — 关于 X 的 X; 层级跃迁的语言。 (ch02, ch04, ch09, ch15, ch16)

**MU 谜题** — 在 MIU 系统中问"能否从 MI 出发推出 MU?" — 否; 用于引入不可判定性直觉。 (对9, 间奏)

**蘑菇 / 蘑菇汤** — 乌龟假装品鉴时; 对话常用笑料。 (贯穿对话)

**判断 (Judgment)** — 与证明不同, 是元层的"看到对不对"; 塔斯基不可定义真理性。 (ch17)

**螃蟹卡农 (Crab Canon)** — 倒行卡农; 主题与倒主题同时呈现。 (对8, 对16)

**判定过程 (Decision Procedure)** — 算法可在有限步内判断任意串是否为定理。 (ch01, ch07)

**清晰层次 (Stratified Hierarchy)** — 与"缠结层次"对立; 现实中几乎不存在。 (ch20)

**丘奇 (Alonzo Church)** — λ 演算发明者; 与图灵同代证明不可判定性。 (ch17)

**全 / 完全性 (Completeness)** — 一致系统中每个真命题都可证 — 哥德尔定理表明此对算术系统不成立。 (ch04, ch09, ch14)

**R 任意串规则** — WJU 系统的产生式规则: R → SR 或 R → RS (任意串可复制粘贴)。 (ch01)

**Ricercar / 追寻** — 巴赫《音乐的奉献》中"在多声部中找主题"的赋格; 六部无插入赋格是巅峰。 (导言, 对20)

**三步推理规则 (Three inference rules)** — WJU: R → SR, R → RS, SSS → ε, ε → U 不可逆 (此处略)。 (ch01)

**三层世界 (Three Worlds)** — 侯世达后期提出: 物理 / 符号 / 抽象 — 不可还原。 (ch20 隐含)

**SVG / 自引用类** — 代码引用自身的能力; Quine 类。 (ch14)

**跳蚤 / 跳蚤市场 (Flea Market)** — 比喻: 自指像跳蚤咬自己。 (对话)

**跳出系统 (Jumping out of the System)** — 主动升到元层评估系统本身; 智能核心操作之一。 (ch15, ch17, ch20)

**图灵 (Alan Turing)** — 1936 年停机问题不可判定性证明。 (ch13, ch17)

**图灵机 (Turing Machine)** — 通用计算模型; 与递归函数 / λ 演算等价。 (ch05, ch13, ch17)

**TNT / 印符数论 (Typographical Number Theory)** — 用符号串表示自然数 + 加乘的形式系统。 (ch08, ch14)

**推导 (Derivation)** — 从公理出发的推理序列; WJU / TNT 都基于此。 (ch01, ch08)

**乌龟 (Tortoise)** — 对话主角; 来自芝诺悖论的慢物; 代表"看似追不上实则追上"。 (贯穿对话)

**乌龟 + 阿基里斯 (Tortoise & Achilles)** — 贯穿全书对话的核心角色对; 都来自芝诺。 (全部对话)

**无 / MU** — 同 MU 谜题; 否命题的入口。 (对9, 间奏)

**无门关 (Gateless Gate / Mumonkan)** — 禅宗公案集; 第 9 章引用作为"无门" — 通向真理没有门。 (ch09)

**西尔维斯特 (Sylvester)** — 19 世纪代数; 提到其"对话体"哲学小品。 (ch07)

**系统 (System)** — 形式系统 / 公理化系统的简称; 在本书中常指"完整可描述的一套规则"。 (贯穿)

**形式 (Form)** — 与"内容"对; 形式可描述, 内容需解释。 (ch02)

**形式系统 (Formal System)** — 由公理 + 推理规则组成的封闭系统; 本书核心概念。 (ch01 起贯穿)

**形式无意义 (Formal Meaninglessness)** — 系统内串本身无意义; 意义由外部赋予。 (ch02, ch06)

**蜥蜴 / 蚁 / 螃蟹** — 对话角色 / 隐喻; 象征不同视角的智能体。 (各处对话)

**一致 (Consistent)** — 形式系统不会同时证明 P 和 ¬P。 (ch04, ch09, ch14)

**伊壁鸠鲁 (Epicurus)** — 提到其"无证据不承认"原则; 对应科学态度。 (ch07)

**隐喻 (Metaphor)** — 跨领域映射; 是同构的直觉端。 (ch03)

**印符数论** — 同 TNT。 (ch08)

**映射 (Mapping)** — 对应; 同构的载体。 (ch02, ch05)

**元循环 / 元递归 (Meta-loop)** — 自指系统的循环; 同怪圈但更技术。 (ch15, ch20)

**元语言 (Meta-language)** — 谈对象语言的语言; 一旦升上去就不能用对象语言规则。 (ch07, ch09, ch15)

**语义 (Semantics)** — 形式系统的意义层; 与句法对。 (ch02, ch06)

**原始递归 (Primitive Recursion)** — 每次调用参数严格变小的递归; BlooP 的形式。 (ch13)

**芝诺 (Zeno)** — 古希腊悖论家; "阿基里斯追不上乌龟"是核心。 (ch01 介绍, 全部对话伏笔)

**芝诺悖论 (Zeno's Paradox)** — 看似证明运动不可能; 实际揭示"无限步 ≠ 永恒"。 (对1, ch01, ch20)

**芝诺式 (Zenoian)** — 用无穷细分制造困局; 侯世达式幽默。 (对话)

**一致性 / 完全性** — 见"一致" / "完全性"。 (ch04)

**AI 反思 (侯世达立场)** — AI 不是"算法够复杂就出现理解"; 必须有符号接地。 (ch18, ch19)

**Escher / Escher's Print Gallery** — 同"印刷品"。 (ch03, ch10, ch20)

**Gödel 编码 (Gödel Numbering)** — 把每个符号 / 句对应到唯一自然数; TNT 的核心工具。 (ch08, ch14)

**Print Gallery / 画廊 (Escher)** — 同"印刷品"; 视觉怪圈原型。 (ch03, ch10, ch20)

**Quine** — 输出自己源代码的程序; 与 G 句同构。 (ch14, ch16)

**TNT 串** — 在印符数论中表达自然数 / 命题的符号串。 (ch08, ch14)

**W / S / U / J** — WJU 系统中的基本符号。 (ch01)

**WU 谜题** — 在 WJU 系统中从 WJU 出发, 能否推出 U? 否; 用以体会形式系统与直觉。 (ch01)

**Z / 芝诺 = 同芝诺**。 (各处)
