# 开发、验收与部署清单

## 开发前

- [ ] 已确认主目标、主要访问者、主行动
- [ ] 已确认信息架构（目标 × 深度）与视觉方向
- [ ] 已标记全部待确认事实和敏感内容
- [ ] 已检查现有代码库、构建方式、部署配置和未提交改动
- [ ] 已分清哪些是真实素材、生成素材、缺失素材
- [ ] 若从参考站提取风格：已记录采到的值、已替换掉商业字体、**未复制 Logo / 文案 / 插画 / 独创版式**

## 内容

- [ ] 首屏出现姓名或常用称呼、定位、主行动
- [ ] 项目说明了本人角色、关键决策和结果，不只有缩略图
- [ ] 时间、组织、职位和数字与来源一致（数字注明统计口径/时间）
- [ ] 社交链接带有「这个平台能看到什么」的说明
- [ ] **没有 TODO 占位、Lorem ipsum、测试链接、虚构评价或客户 Logo**
- [ ] 邮箱、电话、地点、客户信息已获得公开确认
- [ ] title、description、分享图（OG）、favicon 已设置

## 交互与可访问性

- [ ] 导航、按钮、表单、外链都可用
- [ ] 当前页 / hover / focus / 加载 / 成功 / 失败状态清晰
- [ ] 键盘可完成主要流程，焦点可见
- [ ] 图片有合适 alt，装饰图不制造噪音
- [ ] 颜色对比 ≥ 4.5:1，信息不只靠颜色传达
- [ ] 支持 `prefers-reduced-motion`
- [ ] 亮/暗两套主题都可读

## 响应式与视觉

- [ ] 检查 360 / 390 / 768 / 1280 / 1440 五档宽度
- [ ] 最长姓名、项目标题、社交描述不溢出
- [ ] 无重叠、无意外横向滚动、无布局跳动（图片固定宽高比）
- [ ] 首屏能辨认本人和网站目标，并露出后续内容线索
- [ ] 作品图清楚呈现真实内容，不被过度裁切或遮罩
- [ ] 卡片、圆角、阴影、强调色全站一致
- [ ] 中文行高 ≥ 1.7，段间距 ≥ 18px

## 技术

- [ ] 生产构建通过（静态站则确认所有页面可访问）
- [ ] 浏览器控制台无影响使用的错误
- [ ] 内部路由和静态资源路径在部署子路径下正确
- [ ] 外链协议正确，新窗口打开带 `rel="noreferrer"`
- [ ] 图片尺寸合理，首屏资源不过大
- [ ] 基本语义结构完整、内容可索引
- [ ] **未把密钥、私有文件、简历原件、平台导出数据打包进站点**

## 发布门（执行部署前逐项确认）

1. 用户**明确授权**发布
2. 明确生产平台、项目、分支、域名
3. 明确网站是公开、受限还是仅预览
4. 已向用户展示「将公开的联系方式与敏感内容清单」
5. 已构建并记录将发布的源版本

## 发布后

- [ ] **访问生产 URL 验证**，而不是只看命令执行成功
- [ ] 检查首页、导航、关键详情页、主行动
- [ ] 验证自定义域名与预览域指向同一版本（预览成功 ≠ 域名生效）
- [ ] 检查分享标题、描述、图片、favicon
- [ ] 报告生产 URL、源版本、验证结果、仍需用户自行处理的账号配置

## 本地预览方式

```bash
cd <site-dir> && python3 -m http.server 8080
```
然后用 claude-in-chrome 打开 `http://localhost:8080`，切亮/暗主题各截一张，再 resize 到 390px 截一张给用户看。
